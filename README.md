# String

A custom C++ `String` class implemented from scratch using manual dynamic memory management.

The project is designed as a learning project to understand how a string implementation works internally without relying on `std::string` for the underlying storage.

The interface and behavior are intentionally kept as close as possible to `std::string`, with only small modifications where appropriate. For example, `is_empty()` is provided instead of `std::string`'s `empty()`.

## Features

* Dynamic memory management with `new[]` and `delete[]`
* `size` and `capacity` management
* Copy constructor and copy assignment
* Move constructor and move assignment
* Append operations
* Insert and erase operations
* Substring extraction with `substr()`
* Searching with `find()`
* Bounds-checked access with `at()`
* Direct element access with `operator[]`
* String comparison and comparison operators
* Iterators
* `reserve()` and `shrink_to_fit()`
* C-string interoperability
* Handling of self-assignment, self-append and aliased data

## Build

The project uses CMake and does not depend on a Visual Studio solution or project file.

```bash
cmake -S . -B build
cmake --build build
```

The `build/` directory is generated by CMake and is not part of the repository.

## Purpose

The main goal of this project is to understand the implementation details behind a dynamically allocated string while staying as close as possible to the interface and behavior of `std::string`.

The implementation focuses on memory ownership, copying, moving, capacity management, string manipulation and aliasing.
